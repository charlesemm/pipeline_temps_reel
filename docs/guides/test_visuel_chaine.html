Test de panne (optionnel)

Réutilise le scénario déjà validé à l'étape 5 — utile pour démontrer la reprise après incident (chapitre 7) sans toucher au terminal.

  1. Dans AKHQ (:8085), section Connects → le connecteur dprest-postgres-source-json → bouton Pause.
  2. Ouvre Grafana → dashboard de supervision. Attends une minute : le pavé État du connecteur Debezium passe en alerte, une notification apparaît dans le bandeau d'alertes.
  3. Relance le connecteur (Resume dans AKHQ) : l'alerte se résout d'elle-même, sans autre intervention.
